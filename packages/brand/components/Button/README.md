# Button

A 44px-tall button or link in three forms: primary (`primary-glass` fill, `on-primary` text), secondary (clear glass, `text`), and icon (`.sm-icon-btn`, 44 × 44, round with `.sm-round`).

- One primary button per view.
- On an opaque ground, add `.sm-solid` to a primary button for a solid `primary` fill.
- An icon button carries an `aria-label`; its SVG is `aria-hidden`.
- Labels are verbs in sentence case ("Practise this shape").
- Use `<button>` for actions and `<a href>` for navigation, never a clickable `<div>`.
