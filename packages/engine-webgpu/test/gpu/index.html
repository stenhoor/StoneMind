engine-webgpu: GPU check

Runs the WebGPU network on the golden positions and compares it with the outputs captured from native KataGo; optionally measures evaluations per second by batch size. A developer page, served by scripts/gpu-check.mjs or from the project's GitHub Pages site.


Without a file, the page uses the model in its model parameter, or else the test network. Goldens exist for kata1-b18c384nbt-s9996604416-d4316597426 and the test network.
