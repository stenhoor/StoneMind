# StoneMind Ontology Seed v0.1

Version: 0.1

Status: Initial Seed Ontology

Purpose:
Provide the initial concept inventory for the StoneMind Go Ontology.

This document is not intended to define every concept in Go.

Instead, it identifies the first generation of concepts, relationships, and organizing structures from which the full ontology can evolve.

---

# Ontology Philosophy

Go is not a collection of isolated ideas.

Go is a network of interconnected concepts.

StoneMind models:

- Concepts
- Relationships
- Dependencies
- Emergent Understanding

The ontology exists to support:

- Player Modeling
- Style Modeling
- Coaching
- Recommendations
- Learning Pathways

---

# Ontology Levels

The ontology is organized into several levels.

```text
Level 0

```

# Ontology Success Criteria

The ontology succeeds when it enables StoneMind to answer:

- What does this concept depend on?
- What concepts support this concept?
- What concepts does the player understand?
- What concepts are holding the player back?
- What concepts reinforce the player's style?
- What concepts should be studied next?
- Why?

The purpose of the ontology is not to catalog Go.

The purpose of the ontology is to help players understand and unlock their Go.
