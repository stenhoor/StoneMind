77–97% SM on GPU 0. GPU 0 power peaked at 109.67 W. The owner's own Edge and its settings were not changed.
`vulkaninfo --summary` lists both GPUs: Intel(R) UHD Graphics (TGL GT1), Mesa, and NVIDIA GeForce RTX 3080 Laptop
GPU, NVIDIA.

### How the runs were done

`scripts/gpu-check.mjs --serve` was started once per browser, with `--out /tmp/gpu-check-<browser>.json`.
**Check and benchmark** was pressed:
- **Edge (Intel):** by Claude, through the Claude in Chrome extension, which runs in the owner's Edge on this machine.
- **Edge (NVIDIA):** by a script over the Chrome DevTools Protocol in the separate instance, which set controls through
  the DOM (`button.click()`).
- **Firefox:** by a script over Firefox's built-in WebDriver BiDi, with Firefox started as
  `firefox --remote-debugging-port 9222` on the owner's profile.

The runs went one after the other, never at the same time. The benchmark times one warm-up evaluation and then 5 timed
evaluations per batch size, and reports the median (`runs = 5` in `test/gpu/check.js`). It uses the 19×19 position
repeated to fill each batch.
