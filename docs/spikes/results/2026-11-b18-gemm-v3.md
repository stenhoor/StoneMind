# Spike 0001: GEMM v3 (b18) on Edge (NVIDIA)

Date: 2026-11-26 (UTC). Machine: the owner's Linux laptop. Code: branch `spike-0001/gemm-v3`, on top of `main` at
`783dd91`. This is kernel speed at batches 16–32. GEMM v3 runs the Winograd GEMMs and the 1×1 convolutions, and it is
now the default (`defaultGemm`) on every vendor except Apple. All values below are quoted from the reports in this
directory.

## GEMM benchmark

The page's GEMM benchmark times each kernel on its own at b18's three GEMM shapes, in fp16 storage with GPU timestamps.
Each timing is one pass of 30 dispatches, median of 7. `perNetwork` is each kernel's time summed over b18's 62 Winograd
GEMMs (3×3 192→192) and 18 + 18 1×1 convolutions (384→192, 192→384). `ok: true` in both runs: every v3 shape's output
equals v2's exactly (`maxAbsDiffFromV2: 0`), and every kernel matches a float64 product on the CPU.
