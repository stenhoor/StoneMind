# Spike 0001: the v2 Winograd input transform as the default (b18) on Edge (NVIDIA)

Date: 2026-11-26 (UTC). Machine: the owner's Linux laptop. Code: branch `spike-0001/wino-in-v2`, on top of
`spike-0001/steady-bench` (#76). `GpuNetwork` now takes `winoIn` and `winoOut` separately. The input transform's
default is now v2; the output transform's stays v1. `winoTransforms` still sets both. The reason is
`2026-11-b18-steady.md`: the v2 input transform was faster than v1 in all nine steady measurements, while the output
transforms had no consistent order. All values below are quoted from the reports in this directory.

## How it was run

- **Browser:** the separate Edge instance with the launch used in #48:
  `msedge --user-data-dir=<temp dir> --remote-debugging-port=9223 --no-first-run --no-default-browser-check --ignore-gpu-blocklist --use-webgpu-power-preference=force-high-performance`.
  No flags were added. Each run used a fresh instance, one after another.
- **Adapter:** `{"vendor":"nvidia","architecture":"ampere","device":"","description":""}` in every report.
- **GPU check:** `nvidia-smi pmon` showed Edge's GPU process on GPU 0.
