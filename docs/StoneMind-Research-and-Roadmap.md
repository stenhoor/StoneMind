# StoneMind Research and Roadmap

Version: 0.1

# Research Tracks

StoneMind contains multiple parallel research efforts.

---

# Track A - Go Ontology

Goal:

Develop a formal representation of Go knowledge.

Questions:

- What concepts should exist?
- At what granularity?
- How are concepts related?
- How are prerequisites represented?
- How are expert opinions reconciled?

Deliverable:

Go Ontology v1

---

# Track B - Style Modeling

Goal:

Understand how players express themselves through play.

Questions:

- What dimensions define style?
- How is style observed?
- Which behaviors indicate preferences?
- How stable is style?

Examples:

- Tactical ↔ Strategic
- Aggressive ↔ Conservative
- Territorial ↔ Influence
- Local ↔ Whole Board
- Complicated ↔ Simplifying

Deliverable:

Style Framework v1

---

# Track C - Player Modeling

Goal:

Create an evolving representation of the player.

Questions:

- What gets measured?
- How is confidence represented?
- How are strengths represented?
- How are weaknesses represented?

Deliverable:

Player Graph v1

---

# Track D - Heuristic Engine

Goal:

Transform observations into understanding.

Inputs:

- Games
- Problems
- Teaching Games

Questions:

- How is evidence weighted?
- How are graph updates calculated?
- How are relationships inferred?

Deliverable:

Inference Engine v1

---

# Track E - Coaching System

Goal:

Determine how StoneMind acts.

Roles:

- Coach
- Tutor
- Teacher
- Trainer
- Analyst
- Practice Partner

Questions:

- When should each role be activated?
- How should recommendations be generated?
- How should goals influence behavior?

Deliverable:

Coaching Framework v1

---

# Track F - Platform Architecture

Goal:

Define technical foundation.

Topics:

- Smaltworks integration
- OPFS persistence
- Local-first architecture
- Synchronization
- Backup
- Export

Deliverable:

Platform Specification v1

---

Connect StoneMind with the ecosystem.

Targets:

Deliverable:

Integration Framework v1

Create the world's most capable open and player-centric Go coaching platform.

Not by teaching a single way to play Go.

By helping every player discover, understand, and unlock their Go.
