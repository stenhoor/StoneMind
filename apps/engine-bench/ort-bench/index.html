onnxruntime-web baseline

Spike 0001's baseline: KataGo's own ONNX graph (katago dumponnx) run by onnxruntime-web, with its WebGPU and WASM execution providers. It checks the outputs against native KataGo's goldens and measures evaluations per second by batch size, the same way as the GPU check page measures the WebGPU engine. A developer page; the product never loads onnxruntime-web.
